# Stratton CRM

Frontend CRM application built with Vite + Vue + TypeScript. This README points to the main code areas so you can navigate quickly.

## Project structure

- `src/router` - app routes
- `src/views` - page-level views
- `src/components` - shared UI components
- `src/store` - state management
- `src/services` - API and integration helpers
- `src/assets` - static assets
- `public` - static public files
- `vite.config.ts` - Vite configuration
- `src-tauri` - Tauri desktop wrapper (optional)

## Development

Local dev in the full stack uses the `dev/` docker-compose at the repo root.
